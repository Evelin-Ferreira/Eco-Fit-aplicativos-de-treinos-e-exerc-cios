# EcoFit

Aplicativo web voltado para o monitoramento de rotinas de exercícios físicos, caminhada e calistenia, incentivando a prática de atividades e a pontuação por esforço físico.

## 🚀 Sobre o Projeto

O **EcoFit** foi desenvolvido para auxiliar no acompanhamento de treinos diários de forma simples e intuitiva, contando com alternativas adaptadas para diferentes mobilidades. 

## 📋 Metodologia e Organização (Trello)

O gerenciamento de tarefas, o planejamento das sprints e o acompanhamento do progresso de desenvolvimento deste projeto são organizados através do **Trello**. O fluxo de trabalho utiliza quadros divididos nas seguintes etapas:
* **A Fazer (To Do):** Funcionalidades e telas planejadas.
* **Em Andamento (Doing):** Tarefas ativas no momento de codificação.
* **Concluído (Done):** Etapas finalizadas e testadas.

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estrutura semântica das páginas.
* **CSS3:** Estilização visual e design responsivo.
* **JavaScript:** Interatividade e lógica da aplicação.
